Step 3. Part 2, the pre-commit hook

.githooks/pre-commit has two lines.

#!/bin/sh
exec powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/pre-commit.ps1

scripts/pre-commit.ps1 checks the staged files only and exits at once when none is staged. These are the lines that do the work.

Python 
$python = @(git diff --cached --name-only --diff-filter=ACM | Where-Object { $_ -like "*.py" })
if ($python.Count -eq 0) { exit 0 }

python -m ruff check --force-exclude @python
exit $LASTEXITCODE

scripts\check.ps1 gains Step "ruff" { python -m ruff check . } before the tests.

.NET 
$code = @(git diff --cached --name-only --diff-filter=ACM -- '*.cs')
if ($code.Count -eq 0) { exit 0 }

& dotnet format whitespace --folder --verify-no-changes --include @code
if ($LASTEXITCODE -ne 0) {
    Write-Host 'Layout does not match .editorconfig. Fix it with: dotnet format whitespace --folder --include <files>'
    exit 1
}
exit 0
